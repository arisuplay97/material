SOP Integrasi QGIS ke WebGIS Realtime (PostGIS)

Sistem Informasi Spasial Pelanggan & Jaringan Pipa PDAM Tirta Ardhia Rinjani

Versi 1.0 (Produksi)
Oktober 2026
Tujuan Panduan: Menghubungkan software QGIS di komputer teknisi kantor dengan WebGIS secara langsung (realtime) menggunakan database PostgreSQL + PostGIS. Apapun yang digambar teman Anda di QGIS (garis pipa, katup valve, batas zona) otomatis tampil di browser detik itu juga tanpa perlu ekspor-impor file manual!
1
Ambil File Skema Database dari Laptop Anda

File skrip database sudah disiapkan lengkap di laptop Anda.

  1. Buka File Explorer di laptop Anda, masuk ke direktori: 
    D:\ari\Material-Tracker\Material-Tracker\
  2. Cari satu file bernama: postgis_pdam_schema.sql
  3. Copy file tersebut ke Flashdisk atau kirimkan ke diri Anda sendiri lewat WhatsApp Web / Email agar bisa dibuka di komputer server kantor.
2
Eksekusi Skrip di Komputer Server Kantor (pgAdmin)

Lakukan langkah ini di komputer kantor tempat PostgreSQL terpasang:

  1. Buka aplikasi pgAdmin 4 (aplikasi standar PostgreSQL).
  2. Masukkan master password admin saat diminta.
  3. Buat Database Baru:
    • Di menu kiri: klik kanan pada Databases ➔ pilih Create ➔ klik Database...
    • Ketik nama database: pdam_gis lalu klik Save.
  4. Jalankan File SQL:
    • Klik database pdam_gis yang baru dibuat.
    • Di menu atas, klik Tools ➔ pilih Query Tool.
    • Buka file postgis_pdam_schema.sql (bisa buka lewat Notepad, lalu Copy All ➔ Paste ke layar Query Tool pgAdmin).
    • Tekan tombol keyboard F5 (atau klik tombol ikon ▶ Run / Execute).
    • Tunggu hingga muncul pesan notifikasi hijau: "Query returned successfully".
  5. Cek Alamat IP Komputer Kantor:
    • Buka Command Prompt di komputer kantor (tekan tombol Win + R ➔ ketik cmd ➔ Enter).
    • Ketik perintah: ipconfig lalu tekan Enter.
    • Catat nomor IPv4 Address (Contoh: 192.168.1.50).
Penting (Membedakan IP): Ambil angka pada baris IPv4 Address (misal 192.168.1.50). JANGAN ambil Default Gateway (192.168.1.1) karena itu adalah IP modem router internet kantor!
3
Hubungkan QGIS Teman Kantor & Pindahkan Pipa (5 Detik)

Duduk bersama teman Anda yang memegang software QGIS, lalu lakukan:

A. Sambungkan QGIS ke Database Kantor:

  1. Buka software QGIS di komputernya.
  2. Di panel kiri (panel Browser), cari logo gajah bertuliskan PostGIS.
  3. Klik kanan pada tulisan PostGIS ➔ pilih New Connection... (Koneksi Baru).
  4. Isi form sebagai berikut:
    Kolom FormNilai Isian
    NameDatabase PDAM Kantor (bebas)
    Host192.168.1.50 (masukkan IP komputer kantor tadi)
    Port5432 (default PostgreSQL)
    Databasepdam_gis
    User / PasswordUser (biasanya postgres) dan password database kantor
  5. Klik tombol Test Connection. Begitu muncul pesan hijau sukses, klik OK.

B. Pindahkan Garis Pipa (Trik Cepat Drag & Drop):

  1. Buka layer jaringan pipa yang biasa dikerjakan teman Anda di layar QGIS.
  2. Cukup Klik & Tahan (Drag) layer pipa tersebut dari panel Layers.
  3. Lepaskan (Drop) ke dalam folder: PostGIS ➔ Database PDAM Kantor ➔ public.
  4. Selesai! Puluhan ribu garis pipa langsung otomatis ter-upload ke database kantor.
Catatan Nama Kolom / Atribut: Teman Anda bebas memakai nama kolom apapun di QGIS (misal diameter dinamai DIA, DN, UKURAN, atau bahan dinamai BAHAN, MATERIAL). Sistem WebGIS sudah dilengkapi Pendeteksi Alias Cerdas sehingga seluruh data pasti otomatis terbaca!
4
Konfigurasi Pengaturan .env di Laptop Anda

Kembali ke laptop Anda (pastikan laptop Anda tersambung ke Wi-Fi kantor yang sama):

  1. Buka file .env di root folder proyek aplikasi Anda: 
    D:\ari\Material-Tracker\Material-Tracker\.env
  2. Ganti baris pertama DATABASE_URL dengan alamat IP dan password database kantor: 
    DATABASE_URL="postgresql://postgres:password_kantor@192.168.1.50:5432/pdam_gis"
  3. Penjelasan Komponen URL:
    • postgres = Username database server kantor.
    • password_kantor = Ganti dengan password asli database kantor.
    • 192.168.1.50 = Ganti dengan IP IPv4 komputer server kantor tadi.
    • 5432 = Nomor port default PostgreSQL.
    • pdam_gis = Nama database yang dibuat di pgAdmin.
  4. Tips Cadangan: Simpan database lama Anda dengan menambahkan tanda pagar (#) di depannya agar tidak hilang. 
    # Database Kantor (Aktif):
DATABASE_URL="postgresql://postgres:password_kantor@192.168.1.50:5432/pdam_gis"

# Database Cloud Neon (Cadangan):
# DATABASE_URL=postgresql://neondb_owner:npg_9EDmOqw2ZYiQ@...
  5. Tekan tombol keyboard Ctrl + S untuk menyimpan file .env.
5
Selesai! Buka dan Periksa WebGIS Anda
  1. Buka browser di laptop Anda, akses alamat: 
    http://localhost:5173/gis
  2. Perhatikan tombol pill di bagian atas peta: [🔵 QGIS Pipa ✓].
  3. Fitur yang Otomatis Aktif:
    • Pewarnaan & Ketebalan Pipa: Pipa transmisi besar (merah tebal), pipa distribusi utama (biru sedang), dan pipa retikulasi pemukiman (biru muda).
    • Hover Tooltip: Lewatkan kursor di atas pipa untuk melihat nama jalur secara instan.
    • Klik Pipa (Popup Spesifikasi): Muncul kartu rincian teknis lengkap (Diameter mm, Material, Tekanan Bar, Panjang, Zona DMA, Status Aliran).

Tips Mengatasi Kendala (Troubleshooting)

Gejala / Pesan Error Penyebab Solusi Cepat
Connection timed out / Connection refused (port 5432) Firewall di komputer server kantor memblokir akses port PostgreSQL dari laptop lain. Di komputer server kantor: Buka Windows Defender Firewall with Advanced Security ➔ Inbound Rules ➔ Buat New Rule ➔ Port 5432 ➔ Allow Connection.
no pg_hba.conf entry for host PostgreSQL belum mengizinkan koneksi dari IP Wi-Fi lokal. Buka file pg_hba.conf di server kantor, tambahkan baris di paling bawah: host all all 0.0.0.0/0 md5 lalu restart PostgreSQL service.
Peta di laptop belum berubah setelah diedit teman File QGIS belum ditekan tombol Save. Minta teman kantor menekan Ctrl + S (Save Layer Edits) di QGIS. Di WebGIS klik tombol 🔄 Sync.
