1
Siapkan Database di Komputer Server Kantor
Lokasi: Server Kantor

Tujuan: Mengaktifkan database PostgreSQL dan fitur PostGIS agar siap menampung puluhan ribu garis pipa.

  1. Bawa File Skrip: Dari laptop Anda, copy file postgis_pdam_schema.sql (lewat Flashdisk / WA) ke komputer server kantor.
  2. Buka pgAdmin 4 di Komputer Server Kantor: Masukkan password admin PostgreSQL saat diminta.
  3. Buat Database Baru:
    • Di menu kiri: klik kanan Databases ➔ pilih Create ➔ klik Database...
    • Ketik nama: pdam_gis lalu klik Save.
  4. Jalankan Skrip:
    • Klik database pdam_gis yang baru dibuat ➔ klik menu atas Tools ➔ pilih Query Tool.
    • Buka file postgis_pdam_schema.sql (bisa dibuka dengan Notepad ➔ Copy All ➔ Paste ke layar Query Tool pgAdmin).
    • Tekan tombol keyboard F5 (atau klik tombol ikon ▶ Run).
    • Tunggu 2 detik sampai muncul pesan sukses hijau: "Query returned successfully".
  5. Cek Alamat IP Komputer Server:
    • Tekan tombol Win + R di keyboard server kantor ➔ ketik cmd ➔ Enter.
    • Ketik perintah: ipconfig lalu tekan Enter.
    • Catat nomor IPv4 Address (Contoh: 192.168.1.50).
Ingat Perbedaan IP: Ambil angka pada baris IPv4 Address (misal 192.168.1.50). JANGAN ambil Default Gateway (192.168.1.1) karena itu IP modem router Indihome/internet kantor!
2
Pasang WebGIS di Komputer Server Kantor
Lokasi: Server Kantor

Tujuan: Menjadikan komputer kantor sebagai server mandiri agar WebGIS bisa diakses siapa saja di kantor tanpa tergantung laptop Anda.

  1. Di komputer server kantor, buka Command Prompt (CMD) lalu download kodingan terbaru dari GitHub: 
    git clone https://github.com/arisuplay97/material/
cd material
  2. Pasang dependensi sistem: 
    pnpm install
  3. Buat satu file bernama .env di dalam folder material tersebut. Isikan baris berikut: 
    DATABASE_URL="postgresql://postgres:password_kantor@localhost:5432/pdam_gis"
    *(Ganti password_kantor dengan password pgAdmin kantor Anda. Pakai kata localhost karena databasenya ada di komputer server itu sendiri).*
  4. Nyalakan WebGIS agar bisa diakses seluruh kantor: 
    pnpm run dev --host
    *(Opsi --host memastikan WebGIS bisa dibuka oleh perangkat lain lewat Wi-Fi kantor).*
3
Setting QGIS Teman Kantor (Alur Kerja Realtime Otomatis)
Lokasi: Komputer Teman (GIS)

Tujuan: Menghubungkan QGIS teman Anda langsung ke server kantor. Apapun yang digambar langsung tersimpan otomatis!

A. Sambungkan QGIS ke Server Kantor (Cukup 1 Kali Saja):

  1. Di komputer teman Anda, buka software QGIS.
  2. Di panel kiri (panel Browser), cari tulisan gajah PostGIS.
  3. Klik kanan PostGIS ➔ pilih New Connection... (Koneksi Baru).
  4. Isikan form:
    KolomNilai Isian
    NameDatabase PDAM Kantor (bebas)
    Host192.168.1.50 (masukkan IP komputer server kantor dari Tahap 1)
    Port5432
    Databasepdam_gis
    User / PasswordUser postgres dan password database kantor Anda
  5. Klik tombol Test Connection. Begitu muncul pesan hijau sukses, klik OK.
  6. Pindahkan Data Pipa Awal: Cukup klik & tahan (Drag) layer pipa teman Anda, lalu lepaskan (Drop) ke dalam: PostGIS ➔ Database PDAM Kantor ➔ public. Selesai!

B. Alur Kerja Harian Teman Anda (100% Realtime Otomatis):

Mulai sekarang teman Anda bekerja dengan cara praktis ini:
  1. Di QGIS, buka layer pipa langsung dari pohon PostGIS ➔ Database PDAM Kantor ➔ gis_pipa (klik dua kali).
  2. Klik ikon Pensil Kuning (Toggle Editing) di toolbar atas QGIS.
  3. Gambar jalur pipa baru, geser letak katup valve, atau ubah angka diameter pipa.
  4. Begitu selesai, tekan Ctrl + S (Save Edits) di QGIS.
  5. Detik itu juga: Data pipa langsung tersimpan ke server kantor dan langsung otomatis muncul di layar WebGIS seluruh kantor! Tidak perlu kirim file atau ekspor apapun lagi.
4
Cara Membuka WebGIS untuk Seluruh Kantor & Smartphone
Lokasi: Semua Laptop / HP Kantor

Semua staf, pimpinan, dan teknisi lapangan yang tersambung ke Wi-Fi kantor bisa langsung mengakses WebGIS:

  1. Buka browser Google Chrome di laptop atau smartphone masing-masing.
  2. Ketik alamat IP server kantor: 
    http://192.168.1.50:5173/gis
  3. Tips Cepat untuk Teman & Pimpinan: Buatkan Shortcut Desktop atau Bookmark bernama "WebGIS PDAM" di komputernya. Setiap pagi mereka tinggal klik satu kali, WebGIS langsung terbuka!
  4. Tampilan Lengkap Otomatis di WebGIS:
    • Garis Pipa Otomatis Berwarna: Pipa transmisi besar merah tebal, pipa distribusi biru sedang, pipa retikulasi biru muda.
    • Ikon Katup Valve: Gate Valve oranye ⚙, PRV pengatur tekanan ungu ⎈.
    • Klik Pipa / Valve: Muncul popup spesifikasi teknis lengkap (Diameter mm, Bahan, Tekanan Bar, Panjang, Zona DMA).
5
Alur Anda Sebagai Developer (Koding di Laptop)
Lokasi: Laptop Pribadi Anda
  1. Laptop Anda murni hanya untuk tempat membuat fitur baru, memoles desain, atau merombak kodingan.
  2. Di laptop Anda, file .env cukup diarahkan ke IP server kantor untuk testing: 
    DATABASE_URL="postgresql://postgres:password_kantor@192.168.1.50:5432/pdam_gis"
  3. Saat Selesai Bikin Fitur Baru:
    • Di laptop Anda: ketik git push (file .env Anda otomatis aman dan tidak ikut ter-push).
    • Di server kantor: cukup ketik git pull.
    • Selesai! Fitur baru buatan Anda langsung dinikmati oleh seluruh kantor secara instan.

Solusi Cepat Kendala (Troubleshooting):

KendalaPenyebabSolusi
Connection Refused (5432) Firewall server kantor memblokir port database. Di server kantor: Buka Windows Firewall ➔ Inbound Rules ➔ New Rule ➔ Izinkan Port 5432.
no pg_hba.conf entry PostgreSQL belum mengizinkan koneksi dari IP Wi-Fi. Buka file pg_hba.conf di folder PostgreSQL server kantor, tambahkan di baris paling bawah: host all all 0.0.0.0/0 md5 lalu restart service PostgreSQL.
