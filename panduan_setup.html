Cara Teman Anda Menghubungkan QGIS ke Database Cloud (Cukup 1 Menit)
Lokasi: Laptop Teman (Bagian GIS)

Beri tahu teman kantor bagian GIS untuk menghubungkan software QGIS-nya ke database cloud kita:

  1. Buka software QGIS di komputernya (bisa dari kantor atau dari rumah).
  2. Di panel kiri (panel Browser), cari logo gajah bertuliskan PostGIS.
  3. Klik kanan tulisan PostGIS ➔ pilih New Connection... (Koneksi Baru).
  4. Isikan data koneksi resmi berikut:
    KolomData Isian Resmi
    NamePDAM Cloud Neon (bebas)
    Hostep-polished-darkness-azqug7at-pooler.c-3.ap-southeast-1.aws.neon.tech
    Port5432
    Databaseneondb
    SSL ModePilih require
    User Nameneondb_owner
    Password[PASSWORD_DATABASE_ANDA] (Gunakan password resmi dari .env / Neon)
  5. Klik tombol Test Connection. Begitu muncul pesan hijau sukses, klik OK.
  6. Pindahkan Data Pipa Awal: Cukup klik & tahan (Drag) layer pipa teman Anda, lalu lepaskan (Drop) ke dalam: PostGIS ➔ PDAM Cloud Neon ➔ public. Selesai!
3
Alur Kerja Harian Teman Anda (100% Realtime Otomatis)
Aktivitas di QGIS
Mulai sekarang teman Anda bekerja dengan cara sangat praktis ini:
  1. Di QGIS, buka layer pipa langsung dari pohon: PostGIS ➔ PDAM Cloud Neon ➔ gis_pipa (klik dua kali).
  2. Klik ikon Pensil Kuning (Toggle Editing) di toolbar atas QGIS.
  3. Gambar jalur pipa baru, geser letak katup valve, atau ubah angka diameter pipa.
  4. Begitu selesai, tekan Ctrl + S (Save Edits) di keyboard QGIS.
  5. Detik itu juga: Data pipa langsung tersimpan ke cloud, dan peta di https://gudangtiara.vercel.app/gis otomatis terupdate seketika!
4
Cara Membuka WebGIS untuk Seluruh Kantor & Smartphone
Siapapun & Dimanapun

Semua staf, pimpinan, dan petugas lapangan tidak perlu install apapun. Cukup buka browser:

  1. Buka Google Chrome di smartphone atau laptop masing-masing.
  2. Ketik alamat resmi WebGIS: 
    https://gudangtiara.vercel.app/gis
  3. Tips Praktis: Buatkan Bookmark atau Shortcut di layar HP/Desktop bernama "WebGIS PDAM".
  4. Fitur Otomatis yang Langsung Tampil:
    • Pipa Transmisi Besar (200-250mm): Otomatis garis merah tebal.
    • Pipa Distribusi Utama (150-160mm): Otomatis garis biru sedang.
    • Pipa Lingkungan / Retikulasi (75-90mm): Otomatis garis biru muda.
    • Katup Valve: Ikon Gate Valve ⚙, Ikon PRV penurun tekanan ⎈.
    • Klik Pipa / Valve: Muncul kartu popup spesifikasi teknis lengkap (Diameter mm, Bahan, Panjang, Tekanan Bar, Zona DMA).
